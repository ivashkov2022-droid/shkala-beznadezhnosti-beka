# Шкала безнадёжности Бека — BHS

Отдельный веб-проект для оценки выраженности негативных ожиданий относительно будущего за последнюю неделю и наблюдения личной динамики.

## Как работает

- 20 утверждений с ответами «верно» или «неверно»;
- ключевой подсчёт и итоговая сумма от 0 до 20;
- три описательные области: отношение к будущему, мотивация и ожидания;
- сравнение с предыдущим прохождением;
- история сохраняется только в браузере пользователя;
- отдельные записи можно удалять;
- данные не отправляются психологу или на сервер.

Результат не является диагнозом и не определяет намерения человека.

## Локальный запуск

```bash
npm install
npm run dev
```

Публичная версия автоматически разворачивается через GitHub Pages.
